# Validation scripts

The [Linux x86 regression tools](linux_x86_regression/) compare legacy matrix
distance correctness and performance across the pre-refactor, pre-fix and fixed
versions. Start with the [Chinese agent instructions](linux_x86_regression/AGENT_INSTRUCTIONS.txt)
or the [English runbook](linux_x86_regression/RUNBOOK.txt).

Run the tools from this checkout; the instructions create separate worktrees for
the three pinned production revisions. This is a focused module regression,
not the full repository test suite.
