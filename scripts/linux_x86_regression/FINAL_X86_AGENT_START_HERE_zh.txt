三、四套基线（六个逻辑版本）
----------------------------
每套 run.py 使用 parent / before / fixed 三个工作树。fixed 的 HEAD 均固定 955ae841，
通过不同补丁重现实际源码；这是兼容现有 run.py 的版本检查，不是说候选仍是 955。
版本须记录 HEAD + 补丁 SHA256 + src/tests tree，映射见 final_revalidation/versions.json。

  BEFORE=f7bd575f09b622a6dd387bcc266d2f3b53fd47c7
  FIXED=955ae841ddb8f10b2ae6e82a50720e2419741ccd
  for NAME in older955 reference7abc linux_final candidate; do
    ROOT="$TASK/$NAME"
    mkdir -p "$ROOT"
    git -C "$REPO" worktree add --detach "$ROOT/parent" "$PARENT"
    git -C "$REPO" worktree add --detach "$ROOT/before" "$BEFORE"
    git -C "$REPO" worktree add --detach "$ROOT/fixed" "$FIXED"
    case "$NAME" in
      older955) PATCH=baseline_955_test_build.patch ;;
      reference7abc) PATCH=reference_7abc_vs_955.patch ;;
      linux_final) PATCH=reference_linux_final_vs_955.patch ;;
      candidate) PATCH=candidate_vs_955.patch ;;
    esac
    git -C "$ROOT/fixed" apply --check "$PKG/patches/$PATCH"
    git -C "$ROOT/fixed" apply "$PKG/patches/$PATCH"
    git -C "$ROOT/fixed" diff --check
    sha256sum "$PKG/patches/$PATCH" > "$ROOT/applied_patch.sha256"
    git -C "$ROOT/fixed" diff HEAD -- src tests > "$ROOT/applied.patch"
  done
  git -C "$TASK/candidate/fixed" diff --exit-code "$CODE" -- src tests

七、x86 代码一致性与必须检查的目标
----------------------------------
1. candidate 与 linux_final：用相同编译参数，从 compile_commands.json 复现
   matrix_sweep.cc、quantized_integer_metric.cc、mips_euclidean_metric.cc 的预处理/目标文件。
   比较去除行标记的预处理token、.text、相关反汇编及调用点。地址/调试路径差异和指令差异
   分开记录；不要只比较完整可执行文件SHA（路径和Build ID可不同）。保留原命令/对象文件。
   不允许为“做出一致结果”删改指令或放宽结果。预期ARM新增分支在x86完全被排除。
2. FP16：全部raw形状，特别IP 1×1 d128/d512；MIPS、IVF不能退化。
3. INT4：单列2～32行；16×16、32×16、32×32及小多列；记录L2/IP 32×1/32×32，
   旧记录IVF；保证x86之前约0.52×before的记录32×1收益仍在，stored moments语义不变。
4. FP32/FP64/INT16、INT8单列/记录/融合MIPS，以及此前13项整数目标全部保留数据。
   前13项具体清单见原Linux报告及旧说明；本轮不能只看FP16 1×1。
5. 任何在两轮都>5%的新增项，必须对比汇编定位并定点复测，保留原始完整扫描数据。
   相同指令/布局效应也要给出证据；一次定点持平不能删除完整扫描回退。
   明确区分相对Linux final的新增项、相对955/7abc的继承项、相对重构前的差异。
6. 不为微形状波动增加全局对齐参数、不改计时器或只对某一版本改编译配置。
   若确实需继续修复，另存最小patch/新实验目录，不覆盖本轮候选；最终重新完整验证。
   改动共享或ARM代码需回传macOS复验；本任务不授权服务器自行提交/推送新修复。
